# For My Chechi ♡

A mobile-friendly birthday surprise website with your five photos, an interactive letter envelope, memory cards, gentle animations, and a little birthday-wish interaction.

## Preview
Open `index.html` in a browser.

## Photo assets
All five photos are already included in the `assets` folder:
- `chechi-main.jpg` — favourite solo photo (pink sweater)
- `memory-1.jpg` — favourite solo photo (saree)
- `memory-2.jpg` — old sibling memory
- `memory-3.jpg` — funny selfie
- `memory-4.jpg` — sibling portrait

Keep the `assets` folder beside `index.html`, `style.css`, and `script.js`. Don't move the images out of it.

## Publish it for her
1. Create a GitHub repository (for example, `chechi-birthday`).
2. Upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Once GitHub Pages finishes deploying, open the website URL shown there.

Note: if the repository is public, anyone with the URL may be able to view the photos. Only publish photos you're comfortable sharing online.
